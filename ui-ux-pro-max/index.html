Seu histórico não precisa terminar em um arquivo JSONL.

$ contexto pronto para continuar

Quando uma sessão cresce, o contexto se perde.

O exportador organiza a conversa para que o próximo passo comece com entendimento, não com adivinhação.

Fluxo direto

De sessão local a handoff útil em três passos.

  1. 01

    Encontre as sessões

    O script lê os arquivos JSONL salvos pelo Claude Code em ~/.claude/projects/.

  2. 02

    Escolha o recorte

    Filtre por projeto, termo ou data para levar apenas o contexto que importa.

  3. 03

    Continue com clareza

    Receba Markdown, índice estruturado e um arquivo de handoff pronto para o próximo ambiente.
